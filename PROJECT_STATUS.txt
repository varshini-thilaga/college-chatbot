=================================================================
TROUBLESHOOTING
=================================================================

If the server doesn't load:
1. Check if port 8000 is available
2. Run: python manage.py check_setup
3. Check the server terminal for errors

If you get slow first response:
- This is normal (model loading)
- Subsequent responses will be fast (0.2-0.5s)

If voice input doesn't work:
- Use Chrome or Edge browser
- Check microphone permissions
- Select correct language from dropdown
